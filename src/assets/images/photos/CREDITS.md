# Photo Credits

Real food photographs bundled with the app under `src/assets/images/photos/`,
sourced from openly-licensed (Creative Commons / public domain) photography via
Openverse and Wikimedia Commons, then cropped/resized locally for use as
offline app assets. Cropping/resizing is the only modification made.

Photos are used to visually represent each menu item's general dish type —
they are stock photography, not photos of the actual HKD Pizza Point kitchen.
Admin can replace any of them with real HKD photography at any time via
Admin → Menu / Deals → upload image.
